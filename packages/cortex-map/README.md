# cortex-map

A cinematic, living 3D knowledge-graph for React — the "war-table" memory map.

Full documentation, screenshots, and live demo:
**https://github.com/StovBuilds/cortex-map**

Not on npm yet. Clone the repo, then `npm install && npm run build -w cortex-map`, and install it into your
app from the folder (`npm install <path-to-repo>/packages/cortex-map`). Steps in the main README.

```tsx
import { CortexMap } from "cortex-map";

<CortexMap nodes={nodes} edges={edges} clusters={clusters} />
```
